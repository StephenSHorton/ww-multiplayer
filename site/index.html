How it works

Everyone plays in their own Dolphin. The app reads your Link's position and pose, shares it with the other players over the network, and draws their Link in your world.

Patch your game

Point the app at your own Wind Waker disc image. It writes a patched copy next to it and never touches the original.

Boot it in Dolphin

Load the patched game and any save. Saves don't have to match between players.

Host or join

One player hosts, the others join with the host's IP. Within a second or two you'll see each other.

Install

You'll need Dolphin (a recent stable build) and your own copy of The Wind Waker, NTSC-U (game ID GZLE01), as an .iso or .ciso.

  1. Download ww-multiplayer.exe with the Windows button above.
  2. Patch your game. Open a terminal in the download folder and run:
    .\ww-multiplayer.exe patch path\to\your-wind-waker.iso

    This creates your-wind-waker-multiplayer.iso next to the original.

  3. Boot the patched ISO in Dolphin and load a save.
  4. Host or join. Double-click ww-multiplayer.exe for the menu, or use the terminal:
    .\ww-multiplayer.exe host YourName
    .\ww-multiplayer.exe join <host-ip> YourName

    If Windows asks, allow it through the firewall. Ctrl+C stops the session cleanly.

  1. Download and untar ww-multiplayer-macos.tar.gz. You get the app, a Finder-clickable WW Multiplayer.app and a setup script.
  2. Clear the download quarantine. The app is ad-hoc signed, not notarized, so macOS blocks it until you run this in the untarred folder:
    xattr -cr ww-multiplayer "WW Multiplayer.app" scripts
  3. One-time Dolphin setup (re-run after every Dolphin update). It makes a copy at ~/Applications/Dolphin.app that the app is allowed to read; your original Dolphin is left alone. No sudo needed.
    ./scripts/setup-mac-dolphin.sh
  4. Patch your game:
    ./ww-multiplayer patch ~/Roms/your-wind-waker.iso
  5. Boot the patched ISO in the ~/Applications/Dolphin.app copy and load a save.
  6. Host or join (or double-click WW Multiplayer.app to host):
    ./ww-multiplayer host YourName
    ./ww-multiplayer join <host-ip> YourName

Playing over the internet

On the same home network, just join the host's LAN IP. Across the internet, the joiner needs to reach the host on TCP port 25565.

Easiest: Radmin VPN

Free, no router setup. Everyone installs Radmin VPN. The host creates a network, friends join it with its name and password, and joiners use the host's Radmin IP (26.x.x.x). If Windows asks, allow ww-multiplayer.exe on all networks. Windows only.

Port forwarding

Works on Windows and macOS. On the host's router, forward TCP 25565 to the host's PC. The joiner uses the host's public IP. Use --port to pick a different port.

What works today

This is an active project; follow along on GitHub.

Works

  • Your friend's Link in your game, at their real position with their real animations
  • Hosting and joining, with automatic reconnect if the connection drops
  • A terminal menu with status, a text minimap and chat

Known limits

  • Outset Island is the most tested. Room and stage changes aren't smooth yet.
  • No built-in NAT traversal: use Radmin VPN or a port forward.
  • Linux can patch and run a server, but can't play yet.

FAQ

Do all players need the same version?
Yes. Check with ww-multiplayer version. A host turns away players on an incompatible version with a message telling them to update.
Do I need a specific version of the game?
Yes: the North American GameCube release, game ID GZLE01, as .iso or .ciso. Already-patched images are detected and skipped.
Why don't you just ship a patched ISO?
That would mean distributing Nintendo's game. The patcher only contains this project's own code plus a list of edits; every original byte comes from your own copy.
How do I check my download is genuine?
Each release includes SHA256SUMS. On Windows, run Get-FileHash ww-multiplayer.exe in PowerShell and compare. On macOS: shasum -a 256 -c SHA256SUMS --ignore-missing.
macOS says the app "could not be verified"
That's the download quarantine. Run the xattr -cr step from the macOS install tab, in the untarred folder.
Something isn't working
Open an issue on GitHub with your OS, Dolphin version and what you saw.
