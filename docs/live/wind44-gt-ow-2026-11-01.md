## GT D2(2): split trials (pass, with stand-in wins)

A refight boss can't be driven by input here. `enemy-kill` and `stage-hop` both refuse during a refight
("a boss refight is in progress"), so each win is a poke of the boss's `*_TRIALS_CLEAR` bit (a stand-in, like wind24's 0x3F10).
1. A in Xboss0 (Gohma `btd` hp 10/10), 0x3240 poked. A dies (life 0) and continues (GanonA r0), then hops `GanonA 0 1`: A's lamp demo sets 0x3904
   (byte 0x39 0x38 -> 0x3C).
2. B (still in Hyrule) hops `GanonA 0 1`. B's log: `a stage change starts: writing 4 story bits`, `set event 0x3240`, `set event 0x3904`
   (plus 0x3B02, 0x3F10 and t08 sw 0x1E, from A's fixture). B's 0x32 = 0xC3 and 0x39 = 0x3C: B loads the hub with Gohma's lamp lit and no demo.
3. Split: A pokes 0x3220, B pokes 0x3210 and 0x3208. Both reload the hub three times. Each load plays one lamp demo, and every bit crosses
   at the next stage change (`set event 0x3220` on B; `set event 0x3208`, `0x3210` on A). After the third reload both games read 0x32 = 0xFF
   (all four clears and 0x3204, `4_door_fin`), 0x39 = 0x3F and 0x3A = 0xA6 (all four lamps). Both games' barrier is gone after a reload.
