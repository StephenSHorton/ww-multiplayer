## Wind Waker Multiplayer v0.3.1

**Requires your own legitimate copy of The Legend of Zelda: The Wind Waker (NTSC-U, GZLE01)** as a `.iso` or `.ciso` file.

**Both players must run the same version.** v0.3.0 and later can't play with v0.2.x: a v0.3.0 host turns a v0.2.x player away with an upgrade message, and a v0.3.0 player joining a v0.2.x host stops with "host runs an older ww-multiplayer". Check with `.\ww-multiplayer.exe version` (Windows) or `./ww-multiplayer version` (macOS).

### Windows

1. Download `ww-multiplayer.exe`.
2. In a terminal opened in the download folder: `.\ww-multiplayer.exe patch path\to\your-wind-waker.iso`
3. Boot the patched ISO in Dolphin.
4. Double-click `ww-multiplayer.exe` for the menu (host or join), or from a terminal: host with `.\ww-multiplayer.exe host [name]`, join with `.\ww-multiplayer.exe join <host-ip> [name]`.

### macOS (Apple Silicon + Intel)

1. Download and untar `ww-multiplayer-macos.tar.gz`. Inside you'll find `ww-multiplayer` (universal binary), `WW Multiplayer.app` (Finder-clickable wrapper), `scripts/setup-mac-dolphin.sh` and `LICENSE`.
2. In Terminal, from the untarred folder, clear the download quarantine (the binary is ad-hoc signed, not notarized): `xattr -cr ww-multiplayer "WW Multiplayer.app" scripts`
3. One-time Dolphin setup (re-run after every Dolphin update): `./scripts/setup-mac-dolphin.sh`. It copies `/Applications/Dolphin.app` to `~/Applications/Dolphin.app` and re-signs the copy without the hardened runtime so ww-multiplayer can read its memory.
4. `./ww-multiplayer patch ~/Roms/your-wind-waker.iso`
5. Boot the patched ISO in the `~/Applications/Dolphin.app` copy.
6. Host: `./ww-multiplayer host [name]` (or double-click `WW Multiplayer.app`). Join: `./ww-multiplayer join <host-ip> [name]`. No sudo needed.

### Verify your download

`SHA256SUMS` lists the SHA-256 of every file above. macOS / Linux: `shasum -a 256 -c SHA256SUMS --ignore-missing`. Windows (PowerShell): `Get-FileHash ww-multiplayer.exe` and compare with the matching line.
