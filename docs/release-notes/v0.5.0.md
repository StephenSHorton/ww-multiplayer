## Wind Waker Multiplayer v0.5.0

See your friend's Link in your game, live. Download the app, double-click it, and it walks you through the rest.

**New in v0.5.0: shared enemies.** The host's game runs the Moblins, Bokoblins and ChuChus, and everyone else sees and fights those same enemies; your hits land on the host's enemy and a kill counts for everyone. Each remote player also has a real body in the host's game that these enemies chase and hit. Other enemy types still run separately on each player's game for now. It is on by default; `WW_ENEMY_SYNC=0` turns it off. The patched disc now runs with 48 MB of Dolphin memory, which the app sets for you on every launch (booting from Dolphin's own game list needs Dolphin 2609 or newer, or that override turned on by hand).

**You need** [Dolphin](https://dolphin-emu.org/) (a recent stable build) and **your own legitimate copy of The Legend of Zelda: The Wind Waker (NTSC-U, GZLE01)** as a `.iso` or `.ciso` file.

**Everyone must run the same version.** A host turns away a player on an incompatible version with a message saying to update (v0.5.0 can't play with v0.4.x or older), and a player whose built-in mods differ from the host's.

**Upgrading?** Patch your vanilla (unmodified) disc again with this version (Setup in the app does it) and boot it from Dolphin's game list. Dolphin save states taken on an older version are refused: load your in-game save and take a new state.

### Windows

1. Download `ww-multiplayer.exe` and double-click it. A console window may flash for a moment; the app window then opens.
2. If Windows shows "Windows protected your PC" (SmartScreen; the exe isn't code-signed), click **More info**, then **Run anyway**.
3. The first time, the app opens on **Setup**: your name and tunic color, your Wind Waker disc (the app writes a patched copy next to it and never changes your original) and Dolphin (found for you, or Browse…).
4. **Host**, or **Join**: pick the host's session from the list when you're on the same network, or paste the join code (`WW-XXXX-XXXX`) or address the host shares. Everyone meets in the lobby; when the others are Ready, the host presses **Start** and each player's Dolphin starts with the patched game.

The window needs Microsoft's WebView2 runtime, which Windows 11 and current Windows 10 have; without it the app offers to install it. If Windows asks, allow `ww-multiplayer.exe` through the firewall.

### macOS (Apple Silicon + Intel, macOS 12 or later)

1. Download `ww-multiplayer-macos.zip` and open it (Safari usually unzips it for you). Move the `WW Multiplayer` folder somewhere permanent, such as Applications.
2. Double-click `WW Multiplayer.app`. If macOS says it can't verify the app (it isn't notarized by Apple): Control-click (right-click) the app, choose **Open**, then **Open** again. On macOS 15 or later, after the first warning go to System Settings → Privacy & Security and click **Open Anyway**.
3. The first time, the app opens on **Setup**: your name and tunic color, your Wind Waker disc, and Dolphin. Press **Prepare Dolphin** once (and again after each Dolphin update): it makes a copy at `~/Applications/Dolphin.app` that the app is allowed to read, and leaves your original Dolphin alone. No password needed.
4. **Host** or **Join**, then **Start** from the lobby, as on Windows.

### Co-op (optional)

Shared progress is off unless the host turns it on: in the lobby the host picks **New world** or **Continue**, and the app guides everyone through binding a save file. Plain multiplayer needs none of it.

IP addresses are hidden on screen by default (`•••.•••.•••.42`), so you can stream the app; the host's share card has Show and Copy.

### Advanced: terminal menu and command line

The same program has a terminal menu and a command line. Windows: `.\ww-multiplayer.exe tui`, `.\ww-multiplayer.exe patch <iso>`, `.\ww-multiplayer.exe host [name]`, `.\ww-multiplayer.exe join <host-ip|join-code> [name]`. macOS: in Terminal, `cd` into the unzipped `WW Multiplayer` folder, run `xattr -cr .` once to clear the download quarantine, then `./ww-multiplayer tui` (or `patch`, `host`, `join`); `./scripts/setup-mac-dolphin.sh` does what Prepare Dolphin does. `ww-multiplayer version` prints the version.

### Verify your download

`SHA256SUMS` lists the SHA-256 of every file above. macOS / Linux: `shasum -a 256 -c SHA256SUMS --ignore-missing`. Windows (PowerShell): `Get-FileHash ww-multiplayer.exe` and compare with the matching line.
